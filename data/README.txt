CATALOGO IL RACCONTASTORIE

Il catalogo attuale è contenuto in assets/script.js, nell'array `comics`.
Per la prima versione ho inserito 8 schede DEMO per mostrare il funzionamento del sito.

Per ogni fumetto puoi impostare:
- title = Titolo
- number = Numero
- publisher = Editore
- year = Anno
- edition = Regular / Signed / Variant, ecc.
- type = regular oppure signed
- category = marvel / dc / image
- grade = voto
- grader = CGC / BGS / altro
- era = modern oppure vintage
- description = descrizione
- image = percorso della foto reale, ad esempio "images/spiderman1.jpg"
- new = true per mostrarlo negli Ultimi arrivi

Non è presente il prezzo, come richiesto.
